# Company OS — install

One command. Docker is the only prerequisite.

```bash
curl -fsSL https://raw.githubusercontent.com/HSM-II/company-os-install/main/install.sh | bash
```

For an agent (Claude Code, Codex, or any MCP host), inside the project you work in:

```bash
npx --yes @hsm/company-os-mcp-server connect claude   # or: connect codex
```

`QUICKSTART.md` documents every installer option; `bash install.sh --help`
prints the same list. The image is `ghcr.io/permutationresearch/company-os`,
pulled by immutable digest, and every file here is listed with its SHA-256 in
`DIST_MANIFEST.json` together with the source commit it was built from.

This repository carries the installer only. It is generated by
`scripts/company-os-dist-sync.sh` in the source repository; edits here are
overwritten on the next release.
